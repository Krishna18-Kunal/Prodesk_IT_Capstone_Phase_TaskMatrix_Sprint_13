# AI Usage & Prompt Engineering Log

This file documents AI assistance used during planning and implementation. Update it honestly as you use AI tools; do not claim prompts or generated code that you did not use.

## Planning prompt

"Act as a senior product architect. Help define an MVP PRD for a single-contributor agile project management platform for small software teams. Include user personas, measurable goals, functional and non-functional requirements, scope boundaries, risks and acceptance criteria."

## Architecture prompt

"Design a React + Vite frontend, Express REST API and MongoDB data model for a small-team Kanban project management application. Include users, projects, tasks and activity collections, authentication boundaries, API endpoints and a Mermaid ER diagram."

## UI/UX prompt

"Create a responsive project management interface with a dashboard, project Kanban board and task details view. Prioritize clear hierarchy, accessible controls, mobile responsiveness and simple workflows."

## Implementation prompt

"Review this feature implementation for correctness, input validation, authorization, error handling and maintainability. Explain any security risks and propose focused fixes."

## QA prompt

"Create a manual test checklist for authentication, project CRUD, task CRUD, task assignment, Kanban status changes, filters, dashboard metrics, API authorization and responsive layouts."

## Responsible-use note

AI output must be reviewed, tested and understood by the contributor. Never paste secrets, credentials or real personal/medical data into prompts. Record the actual tools, prompts and changes used during the capstone.
